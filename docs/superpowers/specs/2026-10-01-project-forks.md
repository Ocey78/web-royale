# Web Royale project forks

Create three independent, editable projects from the delivered v0.50.0 build. Preserve Classic byte for byte. Main is the base for future modern features, arenas and online play. Custom is a private base for the user's own cards and abilities. Those future features are not implemented by this split.

Apply shared fixes only to Main and Custom: use each machine's authored directional views without stopping its movement/attack animation; play Tesla's raise and lower transition once and hold its current state; move the outer Princess towers in every 3v3 theme two tiles outward, preserving bridges and navigation lanes, so a Rocket cannot damage two Princess towers.

Keep Main and Custom browser profiles, learning stores, replays, offline AI directories and default launcher ports distinct. Preserve historical replay simulations. Deliver working offline distributions and editable source in separate standard ZIPs and folders.
