# Web Royale 0.58.4 — Ultimate Elixir Pump

**Elixir Pump costs 15 elixir and produces one elixir every six seconds**, 2.5 times as fast as the current normal Collector's fifteen-second interval.

It is available in the Ultimate Clash, Ultimate 2v2 and Ultimate 3v3 deck builders. Their exclusive pool now contains 33 cards. The pump uses the original Collector model, a custom purple portrait and its own description. It inherits the normal Collector's health, deployment, lifetime, status effects and destruction behavior. Existing Builder and Ultimate Mirror rules apply.

The faster interval is derived from the normal Collector's source value divided by 2.5. The normal card is unchanged.

Tests and gameplay/browser checks were intentionally skipped at the user's request. The website build and publication status are recorded under `docs/qa/v0584/`.
