# Web Royale 0.58.16 — Ultimate practice card levels

With **Ultimate cards in normal decks** enabled, Ultimate cards now match the player's King Tower level instead of using a fixed level 11. Normal deck labels, card details, deployed troops and spell stats follow that level. Cards below their inherited rarity's starting level scale down appropriately.

Battle setup uses the actual King Tower level after mode rules and team tower averaging. Dedicated Ultimate modes keep their existing level rules. This King Tower rule takes precedence over manual practice levels for these cards; Mirror keeps its +3 copied-level bonus. Existing saved replays retain their recorded levels.

No tests, simulations or browser gameplay checks were run, as requested. The website build and publication record are in docs/qa/v05816/.
